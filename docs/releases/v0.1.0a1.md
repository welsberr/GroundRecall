# GroundRecall v0.1.0a1

This alpha compatibility release aligns GroundRecall with Epistemap
`v0.1.0a2` and the unified confidence-overhaul contract.

## Included

- Epistemap dependency pin updated to `v0.1.0a2`;
- typed confidence assessments and migration ambiguity reporting;
- governed profile preservation for extraction, source reliability, reviewer
  endorsement, temporal applicability, and Bayesian evidential support;
- expiry, supersession, retraction, archival state, and provenance retained
  separately from historical assessments;
- current/as-of behavior for memory profiles and Bayesian evidence-ledger
  integration.

## Compatibility

Legacy confidence hints remain readable through the compatibility window.
Ambiguous legacy zero values remain reported rather than rewritten.

- `python -m pytest -q`: 126 passed.
